AI NIDS — STEP 3: BINARY BASELINE MODELS

This package creates:

    src\03_train_binary_baselines.py

It does not modify your raw or processed datasets.

PURPOSE

The script compares four binary intrusion-detection candidates:

1. Dummy prior classifier
2. Scalable logistic regression via SGD
3. Random Forest
4. Histogram Gradient Boosting

It uses:

    0 = BENIGN
    1 = ATTACK

The default experiment draws a deterministic, scenario-proportional sample of
400,000 processed flows. The split is:

    64% training
    16% validation
    20% untouched final testing

The model is selected on validation attack-class F2 score. F2 weights recall
more heavily than precision because missed attacks are especially costly in a
NIDS. The selected pipeline is then refitted on training + validation and
evaluated once on the final test split.

INSTALL

Extract NIDS_Binary_Baselines_Step3.zip into:

    C:\Users\esumi\AI-NIDS-Project

Confirm:

    Test-Path .\src\03_train_binary_baselines.py

Expected:

    True

RECOMMENDED FIRST RUN

    python .\src\03_train_binary_baselines.py

The default uses:

    400,000 sampled flows
    120 Random Forest trees
    100 Histogram Gradient Boosting iterations
    Up to 4 CPU workers

Depending on the computer, this may take roughly 10–45 minutes. Leave the
terminal open until [COMPLETE] appears.

LOW-MEMORY / FASTER TRIAL

    python .\src\03_train_binary_baselines.py `
        --sample-size 200000 `
        --rf-trees 80 `
        --hgb-iterations 70 `
        --n-jobs 2

STRONGER LATER RUN

    python .\src\03_train_binary_baselines.py `
        --sample-size 750000 `
        --rf-trees 180 `
        --hgb-iterations 150 `
        --n-jobs 4
